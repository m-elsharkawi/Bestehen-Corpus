UI state contracts · not schemas, not endpoints
Every state below has a designed visual on pages 02, 04, 05
This page is the contract between the design and whatever implements it. It states what the UI must be able to say about a record — which values exist, which combinations are legal, which transitions the interface offers, and what each state looks like. It deliberately says nothing about storage, services, queues or model providers.
